This repository collects Lean proofs for various mathematical
statements from multiple sources.

The subdirectories of `src` are Lean projects that (last I checked)
build as a whole.  However, be aware that it might take many hours to
finish.  The subdirectory `src/latest/` in particular uses the latest
stable release of Mathlib and is thus the primary Lean project of
interest.

* [Erdős problems](ErdosProblems/README.md)
* [arXiv papers](Arxiv/README.md)
* [Boris Bukh's problems](BorisBukh/README.md)
* [100 Theorems](HundredTheorems/README.md)
* [MathOverflow](MathOverflow/README.md)
* [Wikipedia](Wikipedia/README.md)
