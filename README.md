This repository collects Lean proofs for various mathematical
statements from multiple sources.  The primary content of interest is

* solutions to [Erdős problems](ErdosProblems/README.md).

Information about the sources used is available in
[sources.yaml](data/sources.yaml).

Note: The subdirectories of `src` are Lean projects that (last I
checked) build as a whole.  However, be aware that it might take many
hours to finish.  The subdirectory `src/latest/` in particular uses
the latest stable release of Mathlib and is thus the primary Lean
project of interest.

* [arXiv papers](Arxiv/README.md),
* [Boris Bukh's problems](BorisBukh/README.md),
* [100 Theorems](HundredTheorems/README.md),
* [MathOverflow](MathOverflow/README.md),
* [Wikipedia](Wikipedia/README.md).

Information about the sources used is available in
[more_sources.yaml](data/more_sources.yaml).
