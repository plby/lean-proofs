This is a formalized proof of [Erdős Problem 4](https://www.erdosproblems.com/forum/thread/4).

The latest development also proves the stronger FGKMT18 bound: for every
sufficiently large real $X$, some consecutive-prime gap ending at or below $X$
has length $\gg \log X\,\log_2 X\,\log_4 X/\log_3 X$.

It is available for these Mathlib (and Lean) versions:

* [Mathlib/Lean v4.33.0](../src/latest/ErdosProblems/Erdos4.lean) (latest stable release).
