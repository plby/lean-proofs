This formalizes a solution to a problem of Boris Bukh: if `A + B`
contains `S + S` for a basis `S` of `ℝⁿ`, then `|A| + |B| ≥ 2n`.

It is available for these Mathlib (and Lean) versions:

* [Mathlib/Lean v4.33.0](../src/latest/BorisBukh/BasisSubset.lean) (latest stable release).  [Type-check it online!](https://live.lean-lang.org/#project=mathlib-stable&url=https%3A%2F%2Fraw.githubusercontent.com%2Fplby%2Flean-proofs%2Frefs%2Fheads%2Fmain%2Fsrc%2Flatest%2FBorisBukh%2FBasisSubset.lean)
* [Mathlib/Lean v4.32.0](../src/v4.32.0/BorisBukh/BasisSubset.lean).
* [Mathlib/Lean v4.29.0](../src/v4.29.0/BorisBukh/BasisSubset.lean).
